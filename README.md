# 🎮 Steam Game Review Sentiment Analysis

An end-to-end Machine Learning project that analyzes Steam game reviews using Natural Language Processing (NLP) and predicts whether a review is positive or negative.

---

## 📌 Features

- 📊 Interactive Streamlit Dashboard
- 🎮 Game Statistics
- 📈 Dataset Analytics
- 🤖 Real-Time Sentiment Prediction
- 💾 Trained Machine Learning Model

---

## 🛠 Technologies

- Python
- Pandas
- Streamlit
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Joblib

---

## 📂 Dataset

- **730,945 Steam Reviews**
- **735 Steam Games**

---

## 🤖 Machine Learning

- Binary Sentiment Classification
- TF-IDF Feature Engineering
- Logistic Regression
- **Model Accuracy: 90.06%**

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ath14156/Game-Review-Sentiment-Analysis.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
